Marketplace Analytics — SQL-анализ продаж маркетплейса

О проекте
Pet-проект по анализу данных интернет-маркетплейса. Демонстрирует навыки работы с SQL на уровне, применяемом в коммерческих задачах.

 Бизнес-задачи, которые решены
1. Построение сводного отчёта по продажам с автоматизацией через Materialized Views
2. Сегментация клиентов (RFM-анализ) с помощью CTE и оконных функций
3. Выявление дублей в данных (Data Quality) и расчёт чистых метрик
4. Анализ динамики продаж: сравнение месяцев (MoM) через LAG/LEAD
5. Топ товаров по выручке с ранжированием через ROW_NUMBER

 Стек
- PostgreSQL
- SQL: CTE, Window Functions (ROW_NUMBER, LAG, LEAD), JOIN, GROUP BY, HAVING
- Materialized Views для ускорения отчётности
- DBeaver (для работы с БД)
